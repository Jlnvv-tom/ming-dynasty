# 原始数据

`raw/` 目录存放**未经处理**的源表格，本站所有内容均由此抽取。

```
data/
├── README.md          本文件：字段对照与放置说明
└── raw/
    └── 明朝帝王世系&官职品级.xlsx
```

## 表格结构（Sheet1，共 403 行 × 32 列）

源表是一张「多区块并排」的工作表，各区块共用行号但列不同：

| 列区间 | 区块 | 字段 |
| --- | --- | --- |
| A–F | 皇帝辅臣 + 中央政府 | 官属 / 官职 / 品级 / 人数 / 隶属 / 职事 |
| G–L | 地方行政（含土司、卫所） | 官属 / 官职 / 品级 / 人数 / 隶属 / 职事 |
| M–R | 军事机构 | 官属 / 官职 / 品级 / 人数 / 隶属 / 职事 |
| M–P | 派驻地方官 | 官属 / 官职 / 品级 / 职事（无员额列） |
| G–J | 宗室封爵、文武散阶、勋级 | 序列 / 品级 + 阶名 |
| L–Q | 科举取士 | 阶段 / 考试地点 / 时间 / 等级 / 录取结果 |
| T–X | 大明正朔 | 庙号 / 名讳 / 年号 / 在位 / 谥号（含南明五帝） |
| T | 皇室字辈 | 各王房二十字辈诗 |
| AC–AF | 各帝子嗣 | 每帝一行标题，下接皇子条目（长子 / 次子 / … + 名讳 + 封号） |

## 关键口径

- **英宗**在源表中分作「英宗（正统 14 年）」与「复帝（天顺 8 年）」两行，ETL 会合并为一位帝王、两个年号。
- **尚宝司**在中央与地方两处重复登记，ETL 按中央归属去重。
- **品级**取值为：超品 / 正一品 … 从九品 / 未入流 / 无品级；排序权重为 `品级 × 10 + (从品 ? 5 : 0)`。
- **隶属**用于归并所属衙门，例如「吏部文选清吏司」归并为「吏部」；无法归并时退回「官属」列。

## 更新流程

1. 替换或编辑 `raw/` 下的表格（保持区块位置与列序不变）。
2. `pnpm data:import` —— 重新生成 `src/data/*.json` 与 `public/search-index.json`。
3. `pnpm data:check` —— 校验悬空引用、品级解析、在位区间与序位连续性。
4. `pnpm build` —— 重新导出静态站点。
